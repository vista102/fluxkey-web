# XSYD → FluxKey 60 demo 대응표

2026-09-10 UI 정리: 별도 Rapid Trigger 메뉴와 중앙의 중복 입력/RT 카드는 제거했다. 해당 설정은 오른쪽 inspector에서 유지하며, Actuation → 트리거에는 최근 6초 가상 이동거리 그래프(시작/일시정지/기록 삭제/입력 기준선)를 제공한다. 실제 센서 연결은 없다.

대조 기준: 2026-09-09~10, 사용자가 연결해 둔 [XSYD v2 driver](https://xsyd.top/v2-app/device), AE61 Pro, 표시 펌웨어 v0.0.6.0 / 웹 V1.0.0.6.

원본에서는 탭 이동·키 선택과 화면/DOM 읽기만 사용했다. 설정 적용, 교정, 펌웨어 전송은 실행하지 않았다. 이 문서는 **UI 대응**을 다루며 펌웨어 프로토콜 호환을 보증하지 않는다.

## 아이콘 슬롯 대응 근거

아이콘의 CSS 이름을 읽어 슬롯을 대조했다. **클래스 이름은 HID 코드가 아니다.** 한국어 설명은 이름에서 해석한 것으로, 실제 연결 전 툴팁/프로토콜 대조가 필요하다.

- 미디어 14: `bri-plus`, `bri-less`, `next`, `prev`, `Stop`, `play`, `mute`, `vol-plus`, `vol-less`, `music`, `mail`, `Calc`, `computer`, `Browser`.
- 조명 18: `mode`, `Color`, `m-bri-plus`, `m-bri-less`, `spd-plus`, `spd-less`, `m-prev`, `on-off`, `dir`, 그리고 장식부 `d1-*`의 대응 9개.
- 제어 7: `reset`, `win`, `mac`, `config1`–`config4`.
- 마우스 12: `m-free`, `m-left`, `m-right`, `m-middle`, `m-forward`, `m-back`, `m-mlx`, `m-mrx`, `m-muy`, `m-mdy`, `m-whf`, `m-whb`.
- 특수: 빈 출력, 투명(△), Fn0–Fn3. 기본값 복원은 데모 편의 동작이다.

## 아직 1:1 완료라고 할 수 없는 부분

1. 원본 클라우드 업로드·코드 가져오기·로그인은 안내만 제공한다. 데모의 로컬 JSON 백업으로 대체했으며 클라우드 인터랙션 전체를 복제하지 않았다.
2. 과거 펌웨어 목록/업데이트 내역은 확인되지 않아 만들지 않았다.
3. 스위치의 내부 센서 보정계수, 실제 장치 명령/키코드, 데이터 포맷은 미구현이다. `switchModelId` 등은 로컬 식별자다.
4. 고급 키 편집 필드는 대응하지만 센서 기반 실행 엔진 및 원본의 세부 제약 조건은 검증되지 않았다. 테스트 영역은 단순 keydown/keyup 이벤트 뷰어다.
5. LED 효과는 슬롯·설정 편집만 지원하고 20가지 실제 애니메이션은 재현하지 않는다.

새 프로젝트는 외부 요청 없이 동작한다. 브라우저 저장, 파일 가져오기/내보내기만 수행한다. WebHID, 클라우드, 배포, 기존 프로젝트 변경은 이번 작업에 포함하지 않았다.
